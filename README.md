### 👨‍💻 What I Do

- **AI Engineering & Integrations** — Integrate OpenAI and Anthropic APIs into real-world applications, including AI assistants, chatbots, workflow automation, and Retrieval-Augmented Generation (RAG) systems.

- **Full-Stack SaaS Development** — Build end-to-end web applications using Next.js, React, TypeScript, Node.js, Express, and NestJS, from intuitive frontend experiences to backend services and APIs.

- **AI-to-Production Engineering** — Turn applications built with AI coding tools such as Cursor, Bolt, Lovable, and v0 into maintainable, reliable software through debugging, refactoring, code reviews, and architectural improvements.

- **API Development & System Integrations** — Design REST APIs, integrate third-party services, and connect business systems to automate processes and reduce manual work.

- **Database Engineering & Optimization** — Design database schemas, write complex SQL queries, troubleshoot performance issues, and optimize data access using MySQL and Oracle PL/SQL.

- **Performance, Reliability & Maintenance** — Investigate difficult bugs, identify bottlenecks, improve error handling, and make existing applications easier to maintain, extend, and scale.

- **Cloud & Deployment** — Work with Google Cloud Platform, including Cloud Run, Cloud SQL, and Artifact Registry, to deploy and support applications.

- **Business Automation & Analytics** — Build practical workflows and reporting solutions using Airtable, Zapier, GA4, and Looker Studio.
